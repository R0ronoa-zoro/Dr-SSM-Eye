Dr. SSM Eye - Complete Architecture Document for AI Implementation
Project Summary
Dr. SSM Eye is an advanced phishing detection system that analyzes URLs using multi-layered intelligence (threat feeds, visual analysis, brand matching, ML classification) to determine if a URL is Clean, Suspicious, Malicious, or requires Analyst review. The system provides explainable reasoning for every classification decision.
Target Accuracy: 95%+ with <2% false positives
Scale: Personal project, 200 URLs max, 25 per bulk upload
Resource Budget: <3.5GB storage, 300-400MB RAM peak

Module 2.4: Typosquatting Detection (typosquat.py)
Function:
pythondef detect_typosquatting(domain: str) -> ModuleResult:
    """
    Detect typosquatting against known brands
    
    Techniques:
    1. Levenshtein distance (edit distance)
    2. Character substitution (a→@, o→0, i→1, e→3)
    3. Missing characters
    4. Double characters
    5. Homograph attacks (Cyrillic/Greek characters that look like Latin)
    6. Combosquatting (brand + common word)
    
    Process:
    1. Extract base domain (remove TLD)
    2. For each brand in database:
       - Calculate Levenshtein distance
       - Check for character substitutions
       - Check for homographs (Unicode normalization)
    3. If similarity >80%, flag as typosquatting
    
    Scoring:
    - 90-100% similarity: +30 points (obvious typosquat)
    - 80-89% similarity: +20 points (likely typosquat)
    - 70-79% similarity: +10 points (possible typosquat)
    
    Returns: ModuleResult with target_brand: str, similarity: float, 
             technique: str, original: str, typo: str
    """
Homograph Detection:
pythondef detect_homographs(domain: str) -> bool:
    """
    Detect Unicode homograph attacks
    
    Examples:
    - раypal.com (Cyrillic 'а' looks like Latin 'a')
    - аpple.com (Cyrillic 'а')
    - gοοgle.com (Greek omicron 'ο' looks like Latin 'o')
    
    Process:
    1. Normalize domain to Unicode
    2. Check for mixed scripts (Latin + Cyrillic + Greek)
    3. Check confusable characters using confusable_homoglyphs library
    4. Flag if suspicious mix detected
    """
